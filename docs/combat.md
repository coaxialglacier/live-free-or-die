# Live Free or Die — Fun Musket Combat

Working design for action-first black powder fighting: Doom tempo, period texture, reload that never jails the player.

## The problem with musket games

Most musket games treat the reload like history homework. Long authentic waits. The player stands still while the fiction does paperwork. That makes the fun part of the gun the part you do least.

We do the opposite.

**Period weapons. Arcade tempo. Cinematic lethality.**

The musket still feels like a musket: one thunderclap, white smoke, a hard kick, a window after the shot. The player is never punished with empty waiting. Reload is a verb. Close range is a reward. Steel fills the silence between shots.

---

## One-line fantasy

**Fire like a cannon. Close like a wolf. Reload like a showoff.**

Every fight should swing through:

1. **Thunder** — a shot that matters
2. **Smoke** — chaos you can use
3. **Steel** — bayonet, tomahawk, saber, buttstock while the world is still ringing

If a fight is only “shoot, wait, shoot,” it has failed.

---

## Design law: authenticity serves fun

| Keep | Drop |
|------|------|
| One heavy, loud, proud shot | Minute-long authentic reloads |
| Smoke banks that change the fight | Ammo starvation as default |
| Bayonet / tomahawk / saber as first-class | Musket as the only verb |
| Volley lines as readable threats | Drill sim that teaches boredom |
| Powder flash, kick, ringing ears | Realistic misfire spam |
| Stolen pistols as dirty miracles | Inventory clutter |

If a mechanic makes a reenactor nod and a player sigh, cut the sigh first.

## Steal Doom’s real trick

Doom is not fun only because guns are loud. It is fun because **you are never put in time-out**.

Always moving. Always choosing. Always converting one action into the next. Aggression is the resource loop.

We steal that spirit, not the demons.

**Musket law:** firing spends thunder. Reloading never spends your freedom.

---

## Hard rule: reload never jails you

Reloading is always legal. Always.

- Run while reloading
- Sprint while reloading
- Slide / vault / shoulder a door while reloading
- Melee cancel out of reload instantly
- Pistol palm-off mid-reload
- Steal a loaded gun mid-reload
- Climb a fence mid-reload
- Shove a redcoat mid-reload

No “plant your feet and wait.” No animation prison. No huge accuracy death penalty just for existing while loading.

If reload ever feels like a loading screen attached to your hands, it is wrong.

### What reload is instead

A **mobile craft action** you perform while staying lethal.

Think Doom weapon-swap energy: rhythmic, visible, proud, interruptible, never stuck.

Hands work. Feet keep voting for violence.

### “Nothing gets in the way” checklist

| Action during reload | Allowed? |
|----------------------|----------|
| Walk / run / sprint | Yes |
| Jump / mantle / slide | Yes |
| Melee | Yes (cancels or blends) |
| Pistol fire | Yes |
| Aim / hip fire when seated | Yes the instant it’s ready |
| Smoke / vault / shove | Yes |
| Steal a weapon | Yes |
| Soft menu locks in combat | Prefer none |

The only thing that stops a reload is *you choosing another cool verb.*

## The fun loop

```
THUNDER → SMOKE → STEEL → STEAL/RELOAD → THUNDER
```

1. **Thunder** — one glorious shot (Doom shotgun beat)
2. **Smoke** — free cover you created
3. **Steel** — bayonet / tomahawk / saber / buttstock (breach-kill lane)
4. **Steal or finish reload** — grab their loaded musket, or complete yours while sprinting
5. **Thunder again**

The empty musket is not empty fun. It is the prompt: *go get dangerous.*

---

## The musket loop in detail

### The shot is an event

- High impact. Clear knockdown / stagger / kill read.
- Camera hitch, smoke bloom, sound that owns the mix for a beat.
- Misses still matter: splintered fence, dropped hat, panicked coat, dust kick.

You do not spray. You *announce.*

### Reload is skill expression

Default reload is short enough to stay in the fight. Skilled play makes it faster and safer.

Reload has inputs (powder, ball, ram, prime). Success tiers:

- **Clean** — fastest, ready while moving
- **Serviceable** — normal speed
- **Rushed** — even faster; next shot blooms wider or kicks harder
- **Interrupted** — bail into melee (ramrod-in-hand as a nasty close beat)

No lock-in jail. Always bail into steel.

### Smoke is cover you created

Every shot paints a brief smoke bank. Use it to break LOS, flank a volley, vanish (Kalha), sell a bayonet rush (Fitch), or cut a reloading NCO (Traitor).

Smoke is temporary terrain, not only VFX.

### Empty gun = invitation

- Bayonet rush / buttstock / tomahawk / saber
- Shoulder-check into a wall
- Steal a loaded British musket mid-fight
- Snap a concealed pistol for a second thunderclap

Never “I am useless until the bar fills.” Always “I spent my thunder, now I spend their fear.”

## Make reload actively cool

### Perfect-run reload

Reload while sprinting through smoke / past a body / over a wall:

- Faster seat
- Juicier ready *snick*
- Brief legend-tempo bloom on the next shot

### Rage reload

Take a hit while loading? Option to slam-finish faster and uglier: wider shot, meaner sound.

### Chain reload

Breach kill mid-reload auto-completes the next stage. Violence loads the gun.

### Two-gun dishonestly

Fitch fantasy: fire musket, pistol while the musket reload continues as belt/craft progress, back to a nearly-ready musket. Dishonest history. Correct fun.

## Doom techniques → our versions

### Always push forward

**Spark / Nerve / powder-heat:** aggressive plays refill your best toys.

- Stagger → bayonet finish restores a fast pistol round
- Break a volley line → militia echo fires with you
- Keep moving through smoke → perfect-reload window widens

Standing behind a wall forever should feel weaker than crashing the line.

### Breach kills (glory-kill lane)

When an enemy is staggered by shot, shove, or panic:

- Bayonet commitment
- Buttstock crack
- Tomahawk zipper
- Saber riposte that steals a pistol on the way out

Rewards: instant partial reload, dropped loaded sidearm, fear pulse that flinches nearby volleys.

### Weapon piano

Hot swap without fuss: musket, concealed pistols, stolen enemy musket (already loaded), steel.

**Steal-a-load:** crash a reloading coat, rip his primed musket, fire *his* thunder into his friend, keep moving, finish your own reload while you do it.

### Enemy design that forces motion

Readable cast lives in [`enemies.md`](enemies.md). Volley lines, rushers, officers, place-specific pressure in [`combat-pressure.md`](combat-pressure.md).

### No downtime audio/visual

Hands keep doing the bit while the camera stays in the fight: powder flash, ball seat, ramrod blur, pan prime. Reload looks like swagger, not homework.

## Sidearms and dirty miracles

- **Concealed pistols** (Fitch): emergency shots, handshake distance
- **Duelling pistols** (Traitor): slower draw, nastier precision
- **Stolen Crown pistols:** temporary gifts after disarm / crate / officer drop

Pistols keep the sentence from stalling. They do not replace the musket’s weight.

## Trio dialects (shared verbs, different accents)

Shared verbs: **Thunder / Smoke / Steel / Steal.**

### Kalha

Musket as ambush punctuation. Fire from an angle they did not grant. Vanish into smoke. Tomahawk finishes. Terrain is the magazine.

### Elias Fitch

Musket-butt and bayonet as personality. Concealed pistols as dirty comedy. Spark: neighbors start firing when aggression looks like courage.

### The Traitor

Reads the manual in enemy shoulders. Perfect parry into pistol. Calls the reload window. Turns drill into a countdown only you can hear.

## Modes of fight

1. **Street scrap** — pistols, butts, doorways, Spark crowds
2. **Fence fight** — Lexington DNA: walls, corners, rushed reloads, militia echoes
3. **Forest bite** — Kalha tempo: vanish, angled shot, steel, gone
4. **Line break** — Traitor tempo: read the volley, punish the reload, collapse the chorus
5. **Raid panic** — dark workshop, stolen guns, too many doors

Same verbs. Different music.

## Progression without Call of Duty

You do not unlock a tactical railgun in 1778.

You unlock **legend tempo**:

- Cleaner reload inputs / wider perfect windows
- Faster pistol palm-offs
- Stronger smoke reads
- Better stolen-gun handling
- Militia volley call-ins as Spark spends
- Bayonet rushes that chain

The gun stays a musket. The player becomes the myth.

Powder quality, patched barrels, British locks on colonial stocks: trophies and handling flavor from raids. Identity, not DPS spreadsheet. Hear upgrades in [`gun-sounds.md`](gun-sounds.md).

## Tempo targets (feel, not spreadsheet)

| Beat | Feel target |
|------|-------------|
| Musket ready → fire | Instant, weighty |
| Standard reload | Short action beat you can dance through |
| Perfect reload | Fast enough to feel like swagger |
| Pistol draw → fire | Faster than thought, short range |
| Volley telegraph | Long enough to read, short enough to scare |
| Smoke useful window | Long enough for one smart decision |
| Melee after shot | Should feel like the correct greedy choice |

If QA ever says “I was waiting,” the number is wrong.

---

## Hard no’s

- No authenticity lock that freezes controls for long reloads
- No rooted reload stances
- No default ammo poverty
- No musket-only kit that strands you in melee range
- No random misfire as a constant slap (rare story spice only)
- No enemy that is only a bullet sponge
- No UI that makes reload feel like installing a driver
- No “historical” 15–20 second authentic loads as default

Authenticity lives in flint, smoke, kick, bayonet fear, volley drama.  
It does not live in freezing the player.

---

## Success tests

1. Hand the game to someone who loves action games and has never cared about black powder. If they say “I want to fire that thing again,” we won.
2. Mute the HUD. Chain: shot → smoke flank → steal loaded musket → fire that → bayonet the sergeant → perfect-reload yours mid-sprint → shatter the reforming pair. If that chain feels natural, the product is working.
3. If players say “cool, but I wish the gun was faster,” we accidentally shipped a museum.

## North star

**The musket is a thunderbolt you throw while sprinting through history; reloading is how your hands keep time with the violence, never how the game asks you to wait.**
